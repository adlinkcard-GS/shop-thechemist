# ADLINKCARD · Smart Online Shop (template)

New client:
1. **Use this template → Create a new repository** → name it `shop-clientname`
2. Edit **config.js**: `SHOP_CODE` (from the Shop Manager), `TITLE`, `COLOR`, `ICON`
3. **Settings → Pages** → Branch: `main` / root → Save
4. Put the page link in the client's Google Sheet → Settings → **Public link**

Links:
- Shop: `https://adlinkcard-gs.github.io/shop-clientname/`
- Staff: `https://adlinkcard-gs.github.io/shop-clientname/?staff=1`
